# Getting help

- **Chat:** [#lanbat on Libera.Chat](https://web.libera.chat/#lanbat)
  (`ircs://irc.libera.chat:6697/#lanbat`). Ask, then stay around; answers can take a while.
- **Bugs and feature ideas:** open an issue in the relevant repository.
- **Security problems:** report them privately; see [SECURITY.md](SECURITY.md).

Before asking, check the repository's README and `docs/` folder, and the guides at
[lanbat.github.io](https://lanbat.github.io/).
