# Contributing to LAN BAT

Thanks for looking. Every LAN BAT repository is real, running infrastructure published as a
reference, so fixes, documentation improvements and ideas are all welcome.

- **Small fixes** (typos, docs, an obvious bug): open a pull request directly.
- **Larger changes** (a new feature, a restructure): open an issue first so the approach can be agreed.
- **Questions**: ask in [#lanbat on Libera.Chat](https://web.libera.chat/#lanbat) or open an issue.

A repository with its own `CONTRIBUTING.md` (such as
[nixconf](https://github.com/lanbat/nixconf/blob/master/CONTRIBUTING.md)) has
project-specific steps; follow those.

## Pull requests

- Keep each pull request focused on one change.
- Say how you tested it.
- Never commit real IP addresses, domains, SSH keys, API tokens or plaintext secrets.

## Security issues

Please don't open public issues for vulnerabilities. See [SECURITY.md](SECURITY.md).

By taking part you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
